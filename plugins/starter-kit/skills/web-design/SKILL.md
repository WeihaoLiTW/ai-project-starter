# 網頁設計

使用者不是設計師，看不出「哪裡怪」，只會覺得「怎麼看起來很像 AI 做的」。
你要在他開口之前就把這些地方處理好。

## 版面克制

一個畫面只留一個焦點，其他東西安靜下去——不要每個區塊都用一樣大的標題、
一樣搶眼的顏色互相打架。留白留夠，元素之間不要擠在一起喘不過氣。
字級要有清楚的層級：標題、次標題、內文一眼就分得出誰是誰，不要全部差不多大。

## 排版

中文字不要選太粗的字重，整段黑壓壓的字重看起來很硬。行高要夠，
中文行高比英文更需要留空間，太擠會看起來像沒排版過。標題跟內文的對比要明顯
（字級、字重都拉開差距），不要讓人要瞇眼才看得出哪句是標題。

## 顏色

一個主色就夠，其他地方用中性色（灰、白、黑）襯托，不要到處都上色。
避開一眼就看得出是 AI 預設的配色：過飽和的紫色/藍色漸層背景、
三張長得一模一樣只換文字的卡片排成一排。寧可少用色，也不要用得到處都是。

## 產出

交出去的是一個自包含的單一頁面：樣式寫在同一個檔案裡（`<style>` 內嵌，
不額外開 CSS 檔要他自己連結）、字型用系統內建字（不連外部字型服務）、
不依賴任何外部資源（CDN、圖床、外部 API）。這樣他直接雙擊打開檔案就能看到
成果，不用架伺服器、不用裝套件，符合非技術者自己也能跑得動的前提。
