# 開場白

這段話是要貼給**對方的 Claude** 看的，不是給你自己讀的說明。整段複製，貼進
Cowork 的新對話，送出。

貼進去的當下，這個 plugin 還沒裝，行為層的三支柱（怎麼講話、怎麼動手、怎麼決定）
也還沒生效。所以這段話自己帶了最小一組行為指示，撐到 plugin 裝好為止。

## 貼之前你需要知道的三件事

1. **要用 Cowork，不是 Chat。** 輸入框附近有個模式切換，選 Cowork。Chat 模式沒有
   plugin、沒有檔案系統，這段話貼進去也沒用。
2. **要先確認你的 Claude 方案支援 Cowork。** 目前是 Pro 以上的方案才有。
3. **貼完之後 Claude 會開始問你一些問題、要你去點幾個按鈕。** 那是正常的 ——
   裝 plugin、裝 connector、改設定都是需要你手動同意的動作，Claude 按不到那些
   按鈕。詳細的每一步、每一步要看到什麼畫面，見同一個資料夾底下的
   `walkthrough.md`。

## 貼這一段

```markdown
我完全沒有寫過程式，想用你幫我做一個公司內部要用的小工具。

請你：
- 用繁體中文跟我講話，不要用術語。真的要用的時候，第一次出現先用括號解釋一句。
- 不要問我技術問題。要用什麼資料庫、什麼框架、檔案放哪裡，你直接決定就好，
  決定完告訴我一聲。
- 需要我決定的，請換成我答得出來的問法 —— 講我的工作，不要講程式。
- 讀檔案、寫檔案、跑測試你直接做。只有要刪東西、或要讓公司以外的人看到的時候，
  停下來問我。

第一件事：請幫我裝一個叫 starter-kit 的環境包。
到側邊欄的 Customize → Plugins → Personal plugins 按「+」→ Add marketplace，
輸入 WeihaoLiTW/ai-project-starter，然後裝 starter-kit。
裝好之後，請帶我跑安裝嚮導。
```
