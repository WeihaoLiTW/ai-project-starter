# 訓練前準備（pre-work）

訓練當天你會在自己的電腦上，跟著把開發環境裝起來、實際改一次程式、跑測試、存檔、
上傳到 GitHub。下面兩件事**一定要在報名時、也就是來之前先弄好** —— 當天到場才發現
沒有，就來不及了。

## 兩個一定要先有的東西

- [ ] **Claude Pro（或以上）方案，而且能用 Cowork。**
  Cowork 需要付費方案；沒有付費方案的話，當天到場也開不了 Cowork，整套就裝不了。
  打開 Claude，確認輸入框附近能切到 **Cowork** 模式。

- [ ] **一個已經開好的 GitHub 帳號。**
  GitHub 是放程式碼的地方。開帳號是最花時間的一步，而且講師不能替你開，所以請在家
  先到 github.com 註冊好。當天只會用到「登入授權」那一下。

## 如果你用 Windows，另外先確認這四件

Mac 使用者可以跳過這一段。Windows 上 Cowork 的安裝有幾個地方會**默默失敗**（裝好了
看起來正常，但其實沒有 Cowork），所以請先逐項確認：

- [ ] 用 **`.msix` 安裝檔**安裝 Claude 桌面版（不是 `.exe`）。
- [ ] 安裝時有**系統管理員權限**。
- [ ] 開啟了 **Virtual Machine Platform**（Windows 的一個功能，家用版也有）。
- [ ] 之後要放專案的**工作資料夾在 `C:\Users\<你的使用者名稱>\` 底下** —— 不要放在
  網路磁碟、也不要放在被搬過位置的「文件」資料夾，否則會出現找不到檔案的錯誤。

## 當天你會做到哪裡

裝到「能在自己電腦上改程式、跑測試、存檔、把程式碼上傳到 GitHub」為止。**線上部署
（把東西放到網路上給別人用）不在今天你動手的範圍**，那部分由講師 demo 給你看。
