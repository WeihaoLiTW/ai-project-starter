# 開場白（本機檔位 —— 給訓練當天的學員）

這段話是要貼給**你自己的 Claude** 看的。整段複製，貼進 Cowork 的新對話，送出。

這是「本機檔位」版：它只帶你把環境裝到**能在自己電腦上改程式、跑測試、存檔、上傳到
GitHub**為止 —— 不碰線上部署。訓練當天你動手做的就到這裡，部署由講師 demo 給你看。

## 貼之前你需要知道的三件事

1. **要用 Cowork，不是 Chat。** 輸入框附近有個模式切換，選 Cowork。Chat 模式沒有
   plugin、沒有檔案系統，這段話貼進去也沒用。
2. **要先確認你的 Claude 方案支援 Cowork。** 目前是 Pro 以上的方案才有。
3. **你需要先有一個 GitHub 帳號**（在家先開好）。貼完之後 Claude 會帶你把程式碼上傳到
   GitHub，過程中會請你去點幾個按鈕、登入授權 —— 那是正常的，那些畫面是 GitHub 的，
   不是我們的。

## 貼這一段

```markdown
我完全沒有寫過程式，想用你幫我做一個小工具，今天先把開發環境裝起來。

請你：
- 用繁體中文跟我講話，不要用術語。真的要用的時候，第一次出現先用括號解釋一句。
- 不要問我技術問題。要用什麼資料庫、什麼框架、檔案放哪裡，你直接決定就好，
  決定完告訴我一聲。
- 需要我決定的，請換成我答得出來的問法 —— 講我的工作，不要講程式。
- 讀檔案、寫檔案、跑測試你直接做。只有要刪東西、或要讓別人看到的時候，停下來問我。

第一件事：請幫我裝一個叫 starter-kit 的環境包。
到側邊欄的 Customize → Plugins → Personal plugins 按「+」→ Add marketplace，
輸入 WeihaoLiTW/ai-project-starter，然後裝 starter-kit。

裝好之後，請帶我跑安裝嚮導的「本機檔位」 —— 也就是只裝到「我能在自己電腦上
改程式、跑測試、存檔、把程式碼上傳到 GitHub」為止，不要做任何線上部署的步驟。
```
